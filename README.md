# Odin Etch-a-Sketch

A dynamic, browser-based sketchpad built as part of **The Odin Project's Foundations Curriculum**. This project focuses on heavy DOM manipulation, dynamic event listeners, and responsive layout structuring using CSS Flexbox.

## 🚀 Live Demo

- https://hmarsh14.github.io/odin-etch-a-sketch/

## ✨ Features

- **Dynamic Grid Generation:** Dynamically builds a grid layout completely via JavaScript loops.
- **Interactive Sketchpad:** Implements a `mouseenter` event listener to leave a drawing trail.
- **Random RGB Trails:** (Extra Credit) Generates a completely randomized color spectrum on every individual cell interaction.
- **Custom Canvas Resizing:** Features an interactive control button allowing users to input custom grid dimensions (up to 100x100) with full input validation.

## 🛠️ Tech Stack

- **HTML5** (Semantic structure and layout containers)
- **CSS3** (Flexbox positioning, layout wrapping, and responsive sizing calculations)
- **JavaScript (ES6+)** (Dynamic DOM manipulation, array/loop logic, and event handling)

## 📈 Git Workflow Focus

This project was developed using a strict **Feature-Branch Workflow** to mirror enterprise-level environments (such as CACI). Every structural milestone was isolated into dedicated branches, reviewed, and cleanly integrated into the production-ready `main` branch.

## ⚙️ How to Run Locally

1. Clone this repository:
    ```bash
    git clone https://github.com
    ```
2. Navigate into the project folder:
    ```bash
    cd etch-a-sketch
    ```
3. Open `index.html` directly in your preferred web browser.
